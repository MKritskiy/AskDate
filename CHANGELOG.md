# Changelog

Все заметные изменения проекта AskDate документируются в этом файле.

## [2.0.0] — 2026-06-10

### Добавлено

- **Повторяющиеся события** — создание серий с периодичностью (ежедневно / еженедельно / ежемесячно), настраиваемым интервалом и границами (дата окончания или количество повторений)
- **Виртуальные экземпляры** — при создании регулярного события генерируется только родительская запись; дочерние отображаются на лету в диапазоне ±3–12 месяцев и материализуются при взаимодействии
- **Управление серией** — массовое присоединение / выход / удаление серии событий
- **Названия событий** — необязательное поле, отображается в списке и при просмотре, редактируемое кликом
- **Вкладка «Предстоящие»** — список ближайших событий с карточками, группировкой по датам, постепенной подгрузкой (по 50)
- **Навигация по дням** — кнопки «вперёд» / «назад» в окне просмотра события для перехода к ближайшим дням с событиями
- **Refresh-токены** — автоматическое продление сессии без повторного входа (срок действия 7 дней, ротация при каждом использовании)
- **Подтверждение пароля** — поле «Повторите пароль» в форме регистрации с валидацией на клиенте и сервере
- **CI/CD** — GitHub Actions workflow для автоматической сборки Docker-образов при пуше в `main`, ветка `develop` для разработки
- **Production docker-compose** — `docker-compose.prod.yml` с Watchtower для автообновления контейнеров
- **Локализация календаря** — русские названия месяцев и дней недели в FullCalendar

### Изменено

- Окно просмотра события (`dayPanel`): фиксированный размер (700px × 500px), двухколоночная раскладка, фиксированное позиционирование поверх обеих вкладок
- Кнопка «Удалить отметку» → «Удалить событие»
- Кнопка «Удобно» → «Отметить неудобным»
- При клике на пустой день календаря сразу открывается окно создания события
- Регулярные события в календаре выделены пунктирной оранжевой рамкой с иконкой ↻
- День недели нажатой даты автоматически отмечается в форме создания регулярного события

### Исправлено

- При истечении JWT-токена пользователь корректно перенаправляется на страницу входа с очисткой состояния
- Защита главного экрана: неавторизованный пользователь не видит защищённый контент
- Исправлена генерация еженедельных событий по дням недели — начало от понедельника текущей недели, корректный расчёт дат
- Исправлено мерцание при автообновлении данных — инкрементальное обновление DOM
- Исправлено смещение окна при редактировании названия — фиксированная высота заголовка
- Исправлено перекрытие кнопки «Отмена» и крестика закрытия окна
- Исправлен Internal Server Error при клике на виртуальные события без даты окончания (UTC DateTime)
- Исправлена миграция `AddRefreshTokenToUser` — привязка к DbContext snapshot
- Убраны эмодзи из интерфейса

### Производительность

- Пакетные операции `AddRangeAsync` / `DeleteRangeAsync` в репозитории — ~3 запроса вместо ~910 при создании серии
- Volume mount для `wwwroot` — фронтенд обновляется без пересборки Docker
- Cache-Control: no-cache для статических файлов

## [1.0.0] — 2026-04-18

### Добавлено

- Регистрация и авторизация пользователей (JWT)
- Профили пользователей (имя, фамилия)
- Создание групп с пригласительными ссылками
- Календарь с событиями (FullCalendar)
- Подтверждение участия в событиях
- Комментарии к событиям
- Двуязычный интерфейс (русский / английский)
- Docker Compose для запуска всех сервисов
- nginx как обратный прокси
