# Changelog

Все заметные изменения проекта AskDate документируются в этом файле.

## [2.2.0] — 2026-11-23

### Изменено

- **Занятость и свободность — это разные личные отметки, а не режим интерпретации событий.**
  В 2.1 переключатель «отмечаю свободные / занятые дни» перекрашивал уже поставленные дни; теперь у каждой отметки
  хранится свой тип, и смена инструмента никак не влияет на существующие отметки.
  - «Свободен» — зелёный, «Занят» — красный. Отметка «на весь день» заливает день (у занятого — штриховкой с рамкой);
    интервал показывается плашкой с временем внутри дня.
  - События группы остаются оранжевыми и не считаются занятостью: встреча в 19:30 не означает, что весь день занят.
  - Отметки видны всем участникам группы и не являются событиями: у них нет названия, участников и комментариев.
- **Время в отметках.** Отметка — это весь день или интервал («занят 9:00–12:00», «свободен 18:00–23:00»);
  в одном дне их может быть несколько. Сервер приводит день в порядок: соседние отметки одного типа склеиваются,
  новая отметка перекрывает противоположную по типу («занят 9–12» поверх «свободен 10–14» оставляет «свободен 12–14»).
  Конец дня 23:59 понимается как «до полуночи». Время вводится списками «час : минуты» (24-часовой формат, шаг 5 минут) —
  нативное поле времени следовало локали браузера (AM/PM) и на узких экранах теряло часть суток.
- **Инструменты календаря**: «Просмотр» (клик открывает день) / кисть «Свободен» / кисть «Занят».
  Кисть ставит отметку одним кликом или протяжкой по диапазону; рядом с ней задаётся, что именно она ставит —
  весь день или интервал (настройка запоминается между визитами). Повторный клик по точно такой же отметке снимает её.
  Клавиши `1` / `2` / `3`, `Esc` возвращает просмотр.
- **Панель дня** начинается с блока доступности:
  - «Я: [весь день / с … до …] → Свободен / Занят» — добавляет отметку; ниже списком мои отметки этого дня,
    каждую можно изменить (она загружается в ту же форму) или снять;
  - окно, когда свободны все («Все свободны: 14:00–18:00»), и по строке на каждого участника с полосой-сутками;
  - выбранное событие показывается ниже, с подсказкой, кто занят именно на время события («В 19:30 заняты: Борис»);
  - на вкладке «Предстоящие» панель открывается поверх списка и не переключает вкладку.
- **Полоса доступности группы** внизу дня теперь изображает сутки: зелёным — в это время свободны все,
  красным — кто-то занят, серым — не все отметили.
- «Все свободны» на дне: есть окно не короче 15 минут, в котором никто не занят и никто не «не отметил»,
  и кто-то отметил день явно.
- Настройка «Неотмеченные дни считать свободными» (для тех, кто свободен всегда, кроме отмеченного) — заменила режим 2.1;
  она влияет только на сводку для группы и не меняет смысл отметок. Колонка `Participants.AvailabilityMode` переименована
  в `UnmarkedDaysFree` и сконвертирована на месте: `1 → true`, данные сервера не затрагиваются.
- Названия в интерфейсе: события больше не называются «отметками» (окно создания — «Новое событие», кнопка «+ Создать событие»).
- Кнопка «Сегодня» у календаря локализована (в базовой сборке FullCalendar русские только месяцы и дни).
- Иконки интерфейса (закрыть, навигация по дням, инструменты, уведомления) — единый набор SVG вместо текстовых символов.
- Список участников настройки группы: имя и роль переносятся, а не обрезаются. Рядовой участник удаляет
  из группы только себя; создатель — только других (выйти из своей группы нельзя, иначе она останется без владельца).
- Статические файлы отдаются с `Cache-Control: no-cache` (повторная валидация по ETag) вместо запрета кэширования.
- Экспорт iCal: время события выгружается как локальное, а не UTC.

### Добавлено

- **Права доступа к группам**: данные группы (события, комментарии, отметки доступности, состав) доступны только её участникам;
  вступление — только по ссылке-приглашению. Раньше любому авторизованному пользователю было достаточно знать числовой id группы.
- Ожидаемые отказы сервера (нет записи, нет доступа, неверный аргумент) возвращаются как `404` / `403` / `400` с пояснением
  вместо `500` (глобальный обработчик исключений askdate.web).
- «Очистить мои отметки» в настройках группы; строка «Мои отметки» в статистике.
- Логин (email) и роль показываются в окне профиля; логин продублирован подсказкой у имени в шапке.
- Enter отправляет формы входа, регистрации, создания группы, вступления, комментария и редактирования названия;
  в диалогах фокус получает безопасная кнопка («Отмена» для вопросов), `Esc` закрывает.
- Кнопка «Настройки» рядом с названием группы; открытая группа подсвечивается в списке слева.
- Проверка фронтенда `node tools/check-frontend.mjs`: синтаксис, полнота локализации ru/en, существование id,
  обработчиков и CSS-классов, отсутствие прямой рекурсии и эмодзи.

### Исправлено

- **Сессия обрывалась сама** при истечении access-токена: refresh-токен одноразовый, а несколько одновременных запросов
  (загрузка группы, резервный опрос) или две вкладки отправляли его одновременно и аннулировали друг друга.
  Теперь в пределах вкладки все ожидающие делят один запрос, а между вкладками обновление идёт по очереди.
- Клик по дню со событием открывал одновременно панель дня и окно создания события
- Список групп «мелькал» при смене режима (перерисовывался через скелетон) — теперь обновляется на месте,
  а изменения участников и отметок его вообще не трогают
- Занятые и свободные дни не раскрашивались на выходных (правило выходных перекрывало отметки) и пропадали при наведении курсора
- Окно подтверждения («Удалить комментарий?», «Удалить группу?») становилось невидимым после того, как была
  открыта и закрыта любая другая модалка: затемнённый экран без кнопок (дефект 2.1)
- Кнопка «Сегодня» и подсказки стрелок календаря не переводились при смене языка
- Бейджи событий в календаре обрезались («19:30 · 2 учас…»), на телефоне — до «1…»
- Полосы доступности не появлялись, пока вкладка не показана (отрисовка зависела только от `requestAnimationFrame`)
- На узких телефонах имя в шапке выталкивало кнопки меню за край экрана
- `/User/me` не возвращал email; для события без участников отображался ключ `js.noParticipants`
- Удаление события или группы не их создателем возвращало `500` вместо `403`

## [2.1.0] — 2026-11-23

### Добавлено

- **Режим занятости** — каждый участник выбирает, что он отмечает в календаре:
  - «Отмечаю свободные дни» (по умолчанию) — отмеченные дни показываются зелёным
  - «Отмечаю занятые дни» — отмеченные дни показываются красным, все остальные дни считаются свободными (удобно, если вы доступны всегда, кроме фиксированного времени)
  - Режим сохраняется на сервере для каждой группы отдельно
- **Общие свободные дни** — дни, когда свободны все участники группы, выделяются зелёной рамкой; подсчёт сводки за месяц в легенде
- **Realtime-обновления (SignalR/WebSocket)** — события, комментарии, участники и группы синхронизируются между пользователями мгновенно; индикатор соединения в шапке; резервный опрос при недоступности WebSocket
- **Админ-панель** — список всех пользователей, сброс пароля (с автогенерацией), выдача/снятие роли администратора, удаление пользователя; первый зарегистрированный пользователь становится администратором
- **Время события** — необязательное поле времени (чч:мм) при создании отметки; время отображается в календаре, списке событий и наследуется сериями повторения
- **Создание диапазоном** — выделите дни мышью на календаре, чтобы создать отметки сразу на несколько дней
- **Экспорт iCal (.ics)** — выгрузка календаря группы для импорта в Google Calendar / Outlook / Apple Calendar
- **QR-код приглашения** — быстрое приглашение в группу сканированием
- **Статистика группы** — всего/предстоящих событий, процент вашего участия, самый активный участник, количество общих свободных дней
- **Поиск по предстоящим событиям** — фильтр по названию и создателю
- **Аватары-инициалы** — цветные кружки с инициалами в списках участников и комментариях
- **Горячие клавиши** — `←`/`→` переключение дней, `N` — новая отметка на сегодня, `T` — перейти к текущему месяцу, `Esc` — закрыть окно
- **Браузерные уведомления** — опциональные уведомления при изменениях, когда вкладка неактивна
- **Сводка занятости за месяц** — «В этом месяце: N свободных · M занятых · K общих»
- **Копирование дня** — текстовая сводка событий дня в буфер обмена (для отправки в мессенджер)
- **PWA-манифест, иконка, theme-color** — приложение ставится как отдельное окно
- **Скелетоны загрузки** и дружелюбные пустые состояния

### Изменено

- JWT теперь содержит `profileId` и роль пользователя — подделка заголовка `X-Profile-Id` больше не позволяет действовать от имени другого пользователя
- Day panel на мобильных превращается в bottom-sheet со слайд-анимацией
- Легенда цветов под календарём; подсветка выходных дней
- Улучшены тосты (типы success/error), анимации модалок, фокус-состояния

### Исправлено

- **XSS** — весь пользовательский контент (комментарии, названия, имена) экранируется перед вставкой в DOM
- **Доступ к чужим данным** — Profile API требовал авторизации и проверки владельца; смена пароля теперь только для себя или админа
- **Сброс сессий** — смена/сброс пароля отзывает refresh-токены
- `GetAllAsync` групп больше не загружает все группы из БД (фильтр в SQL)
- Устранён N+1 запросов при выходе из серии событий
- Комментарии кэшируются — меньше запросов при переключении событий
- Ликвидирован 15-секундный опрос — заменён realtime-подписками
- nginx проксирует WebSocket (`/hub`) с корректным upgrade-заголовками

## [2.0.0] — 2026-06-10

### Добавлено

- **Повторяющиеся события** — создание серий с периодичностью (ежедневно / еженедельно / ежемесячно), настраиваемым интервалом и границами (дата окончания или количество повторений)
- **Виртуальные экземпляры** — при создании регулярного события генерируется только родительская запись; дочерние отображаются на лету в диапазоне ±3–12 месяцев и материализуются при взаимодействии
- **Управление серией** — массовое присоединение / выход / удаление серии событий
- **Названия событий** — необязательное поле, отображается в списке и при просмотре, редактируемое кликом
- **Вкладка «Предстоящие»** — список ближайших событий с карточками, группировкой по датам, постепенной подгрузкой (по 50)
- **Навигация по дням** — кнопки «вперёд» / «назад» в окне просмотра события для перехода к ближайшим дням с событиями
- **Refresh-токены** — автоматическое продление сессии без повторного входа (срок действия 7 дней, ротация при каждом использовании)
- **Подтверждение пароля** — поле «Повторите пароль» в форме регистрации с валидацией на клиенте и сервере
- **CI/CD** — GitHub Actions workflow для автоматической сборки Docker-образов при пуше в `main`, ветка `develop` для разработки
- **Production docker-compose** — `docker-compose.prod.yml` с Watchtower для автообновления контейнеров
- **Локализация календаря** — русские названия месяцев и дней недели в FullCalendar

### Изменено

- Окно просмотра события (`dayPanel`): фиксированный размер (700px × 500px), двухколоночная раскладка, фиксированное позиционирование поверх обеих вкладок
- Кнопка «Удалить отметку» → «Удалить событие»
- Кнопка «Удобно» → «Отметить неудобным»
- При клике на пустой день календаря сразу открывается окно создания события
- Регулярные события в календаре выделены пунктирной оранжевой рамкой с иконкой ↻
- День недели нажатой даты автоматически отмечается в форме создания регулярного события

### Исправлено

- При истечении JWT-токена пользователь корректно перенаправляется на страницу входа с очисткой состояния
- Защита главного экрана: неавторизованный пользователь не видит защищённый контент
- Исправлена генерация еженедельных событий по дням недели — начало от понедельника текущей недели, корректный расчёт дат
- Исправлено мерцание при автообновлении данных — инкрементальное обновление DOM
- Исправлено смещение окна при редактировании названия — фиксированная высота заголовка
- Исправлено перекрытие кнопки «Отмена» и крестика закрытия окна
- Исправлен Internal Server Error при клике на виртуальные события без даты окончания (UTC DateTime)
- Исправлена миграция `AddRefreshTokenToUser` — привязка к DbContext snapshot
- Убраны эмодзи из интерфейса

### Производительность

- Пакетные операции `AddRangeAsync` / `DeleteRangeAsync` в репозитории — ~3 запроса вместо ~910 при создании серии
- Volume mount для `wwwroot` — фронтенд обновляется без пересборки Docker
- Cache-Control: no-cache для статических файлов

## [1.0.0] — 2026-04-18

- Календарь с событиями (FullCalendar)
- Подтверждение участия в событиях
- Комментарии к событиям
