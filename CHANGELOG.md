# Changelog

Все заметные изменения проекта AskDate документируются в этом файле.

## [2.1.0] — 2026-11-23

### Добавлено

- **Режим занятости** — каждый участник выбирает, что он отмечает в календаре:
  - «Отмечаю свободные дни» (по умолчанию) — отмеченные дни показываются зелёным
  - «Отмечаю занятые дни» — отмеченные дни показываются красным, все остальные дни считаются свободными (удобно, если вы доступны всегда, кроме фиксированного времени)
  - Режим сохраняется на сервере для каждой группы отдельно
- **Общие свободные дни** — дни, когда свободны все участники группы, выделяются зелёной рамкой; подсчёт сводки за месяц в легенде
- **Realtime-обновления (SignalR/WebSocket)** — события, комментарии, участники и группы синхронизируются между пользователями мгновенно; индикатор соединения в шапке; резервный опрос при недоступности WebSocket
- **Админ-панель** — список всех пользователей, сброс пароля (с автогенерацией), выдача/снятие роли администратора, удаление пользователя; первый зарегистрированный пользователь становится администратором
- **Время события** — необязательное поле времени (чч:мм) при создании отметки; время отображается в календаре, списке событий и наследуется сериями повторения
- **Создание диапазоном** — выделите дни мышью на календаре, чтобы создать отметки сразу на несколько дней
- **Экспорт iCal (.ics)** — выгрузка календаря группы для импорта в Google Calendar / Outlook / Apple Calendar
- **QR-код приглашения** — быстрое приглашение в группу сканированием
- **Статистика группы** — всего/предстоящих событий, процент вашего участия, самый активный участник, количество общих свободных дней
- **Поиск по предстоящим событиям** — фильтр по названию и создателю
- **Аватары-инициалы** — цветные кружки с инициалами в списках участников и комментариях
- **Горячие клавиши** — `←`/`→` переключение дней, `N` — новая отметка на сегодня, `T` — перейти к текущему месяцу, `Esc` — закрыть окно
- **Браузерные уведомления** — опциональные уведомления при изменениях, когда вкладка неактивна
- **Сводка занятости за месяц** — «В этом месяце: N свободных · M занятых · K общих»
- **Копирование дня** — текстовая сводка событий дня в буфер обмена (для отправки в мессенджер)
- **PWA-манифест, иконка, theme-color** — приложение ставится как отдельное окно
- **Скелетоны загрузки** и дружелюбные пустые состояния

### Изменено

- JWT теперь содержит `profileId` и роль пользователя — подделка заголовка `X-Profile-Id` больше не позволяет действовать от имени другого пользователя
- Day panel на мобильных превращается в bottom-sheet со слайд-анимацией
- Легенда цветов под календарём; подсветка выходных дней
- Улучшены тосты (типы success/error), анимации модалок, фокус-состояния

### Исправлено

- **XSS** — весь пользовательский контент (комментарии, названия, имена) экранируется перед вставкой в DOM
- **Доступ к чужим данным** — Profile API требовал авторизации и проверки владельца; смена пароля теперь только для себя или админа
- **Сброс сессий** — смена/сброс пароля отзывает refresh-токены
- `GetAllAsync` групп больше не загружает все группы из БД (фильтр в SQL)
- Устранён N+1 запросов при выходе из серии событий
- Комментарии кэшируются — меньше запросов при переключении событий
- Ликвидирован 15-секундный опрос — заменён realtime-подписками
- nginx проксирует WebSocket (`/hub`) с корректным upgrade-заголовками

## [2.0.0] — 2026-06-10

### Добавлено

- **Повторяющиеся события** — создание серий с периодичностью (ежедневно / еженедельно / ежемесячно), настраиваемым интервалом и границами (дата окончания или количество повторений)
- **Виртуальные экземпляры** — при создании регулярного события генерируется только родительская запись; дочерние отображаются на лету в диапазоне ±3–12 месяцев и материализуются при взаимодействии
- **Управление серией** — массовое присоединение / выход / удаление серии событий
- **Названия событий** — необязательное поле, отображается в списке и при просмотре, редактируемое кликом
- **Вкладка «Предстоящие»** — список ближайших событий с карточками, группировкой по датам, постепенной подгрузкой (по 50)
- **Навигация по дням** — кнопки «вперёд» / «назад» в окне просмотра события для перехода к ближайшим дням с событиями
- **Refresh-токены** — автоматическое продление сессии без повторного входа (срок действия 7 дней, ротация при каждом использовании)
- **Подтверждение пароля** — поле «Повторите пароль» в форме регистрации с валидацией на клиенте и сервере
- **CI/CD** — GitHub Actions workflow для автоматической сборки Docker-образов при пуше в `main`, ветка `develop` для разработки
- **Production docker-compose** — `docker-compose.prod.yml` с Watchtower для автообновления контейнеров
- **Локализация календаря** — русские названия месяцев и дней недели в FullCalendar

### Изменено

- Окно просмотра события (`dayPanel`): фиксированный размер (700px × 500px), двухколоночная раскладка, фиксированное позиционирование поверх обеих вкладок
- Кнопка «Удалить отметку» → «Удалить событие»
- Кнопка «Удобно» → «Отметить неудобным»
- При клике на пустой день календаря сразу открывается окно создания события
- Регулярные события в календаре выделены пунктирной оранжевой рамкой с иконкой ↻
- День недели нажатой даты автоматически отмечается в форме создания регулярного события

### Исправлено

- При истечении JWT-токена пользователь корректно перенаправляется на страницу входа с очисткой состояния
- Защита главного экрана: неавторизованный пользователь не видит защищённый контент
- Исправлена генерация еженедельных событий по дням недели — начало от понедельника текущей недели, корректный расчёт дат
- Исправлено мерцание при автообновлении данных — инкрементальное обновление DOM
- Исправлено смещение окна при редактировании названия — фиксированная высота заголовка
- Исправлено перекрытие кнопки «Отмена» и крестика закрытия окна
- Исправлен Internal Server Error при клике на виртуальные события без даты окончания (UTC DateTime)
- Исправлена миграция `AddRefreshTokenToUser` — привязка к DbContext snapshot
- Убраны эмодзи из интерфейса

### Производительность

- Пакетные операции `AddRangeAsync` / `DeleteRangeAsync` в репозитории — ~3 запроса вместо ~910 при создании серии
- Volume mount для `wwwroot` — фронтенд обновляется без пересборки Docker
- Cache-Control: no-cache для статических файлов

## [1.0.0] — 2026-04-18

### Добавлено

- Регистрация и авторизация пользователей (JWT)
- Профили пользователей (имя, фамилия)
- Создание групп с пригласительными ссылками
- Календарь с событиями (FullCalendar)
- Подтверждение участия в событиях
- Комментарии к событиям
- Двуязычный интерфейс (русский / английский)
- Docker Compose для запуска всех сервисов
