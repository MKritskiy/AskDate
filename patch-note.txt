========================================
  КРУПНЫЕ ИЗМЕНЕНИЯ
========================================

1. АВТОРИЗАЦИЯ
   - Исправлена критическая проблема: при истечении JWT-токена
     пользователь теперь автоматически перенаправляется на
     страницу входа с полной очисткой состояния
   - Добавлена проверка срока действия токена (с буфером 30 сек)
     перед каждым API-запросом
   - Реализована система refresh-токенов (срок действия 7 дней):
     - Автоматическое обновление access-токена при истечении
     - Ротация refresh-токена при каждом использовании
     - Endpoint POST /api/User/refresh для обновления пары токенов
   - Единая точка обработки ошибок авторизации (forceLogout)
   - Защита главного экрана: неавторизованный пользователь
     не видит защищённый контент

2. ПОДТВЕРЖДЕНИЕ ПАРоля
   - Добавлено поле "Повторите пароль" в форму регистрации
   - Валидация совпадения паролей на стороне клиента и сервера
   - Понятные сообщения об ошибке при несовпадении (ru/en)

3. ПОВТОРЯЮЩИЕСЯ (РЕГУЛЯРНЫЕ) СОБЫТИЯ
   - Полная поддержка повторения событий с заданной периодичностью:
     - Ежедневно / Еженедельно (с выбором дней недели) / Ежемесячно
     - Настраиваемый интервал (каждые N дней/недель/месяцев)
     - Границы повторения: дата окончания или количество повторений
     - Пример: "каждый четверг в течение месяца"
   
   - Архитектура виртуальных экземпляров:
     - При создании регулярного события создаётся только родительская
       запись (не генерируются сотни дочерних)
     - Виртуальные экземпляры генерируются на лету для видимого
       диапазона (-3 месяца / +12 месяцев)
     - Подтверждение/отмена участия материализует реальную запись
       по требованию
     - Комментарии к виртуальным экземплярам создают реальную запись
     - Удаление серии работает надёжно, даже если родитель уже удалён

   - Управление серией:
     - "Участвовать в серии" — отмечает участие во всех событиях
     - "Выйти из серии" — снимает участие со всех событий
     - "Удалить серию" — удаляет все события серии (доступно
       только создателю или администратору группы)
     - Независимое подтверждение каждого отдельного дня в серии

4. ВКЛАКА "ПРЕДСТОЯЩИЕ СОБЫТИЯ"
   - Новая вкладка рядом с календарём для просмотра всех
     предстоящих событий списком
   - Группировка по датам с заголовками-разделителями
   - Карточки событий с информацией:
     - Название (если задано)
     - Количество участников и комментариев (с иконками)
     - Статус участия пользователя (удобно/не отмечено)
     - Признак регулярного события (пунктирная оранжевая рамка)
   - Постепенная прогрузка (по 50 событий, кнопка "Показать ещё")
   - При нажатии на карточку открывается окно просмотра события

5. НАЗВАНИЯ СОБЫТИЙ
   - Добавлено необязательное поле "Название" для отметок
   - Отображается в окне просмотра и в списке событий
   - Не отображается в ячейках календаря
   - Возможность редактирования названия у существующих событий
     (клик по названию в окне просмотра)
   - placeholder "Нажмите, чтобы добавить название", если
     название не задано

      для автообновления на сервере

    - Cache-Control: no-cache для статических файлов
    - Ветка develop для разработки, main — для продакшена

========================================
  МОДЕЛЬ ДАННЫХ (Note)
========================================

Новые поля сущности Note:
  - Title (string?) — необязательное название
  - RecurrenceType (enum) — None/Daily/Weekly/Monthly
  - RecurrenceInterval (int) — интервал повторения
  - RecurrenceEndDate (DateTime?) — дата окончания повторений
  - RecurrenceCount (int?) — количество повторений
  - RecurrenceDaysOfWeek (string?) — дни недели (1=Пн, 7=Вс)
  - ParentNoteId (int?) — ссылка на родительскую отметку серии

========================================
  API ENDPOINTS
========================================

Новые endpoints:
  POST   /api/User/refresh                — обновление токенов
  POST   /api/groups/{id}/notes/{id}/confirm/series
                                             — участие в серии
  DELETE /api/groups/{id}/notes/{id}/confirm/series
                                             — выход из серии
  DELETE /api/groups/{id}/notes/{id}/series  — удаление серии
  PUT    /api/groups/{id}/notes/{id}/title   — изменение названия

Изменённые endpoints (поддержка виртуальных ID):
  POST   /api/groups/{id}/notes/{id}/confirm
  DELETE /api/groups/{id}/notes/{id}/confirm
  DELETE /api/groups/{id}/notes/{id}
  GET    /api/notes/{id}/comments
  POST   /api/notes/{id}/comments
