========================================
         PATCH NOTE — AskDate

Версия: v2.1
Дата: 23 ноября 2026
Репозиторий: https://github.com/MKritskiy/AskDate

========================================
  КРУПНЫЕ ИЗМЕНЕНИЯ
========================================

1. РЕЖИМ ЗАНЯТОСТИ (СВОБОДЕН / ЗАНЯТ)
   - Каждый участник группы выбирает режим отметок:
     * «Отмечаю свободные дни» (по умолчанию) —
       отмеченные дни показываются зелёным
     * «Отмечаю занятые дни» — отмеченные дни
       красные, все остальные дни считаются свободными
   - Переключатель в тулбаре календаря; режим
     сохраняется на сервере для каждой группы
   - Сценарий: «я свободен всегда, кроме
     фиксированного времени» — отметить нужно
     только занятые дни, а не всю неделю
   - Миграция AddAvailabilityMode ( Participants.AvailabilityMode )
     применяется автоматически при старте

2. REALTIME-ОБНОВЛЕНИЯ (SIGNALR / WEBSOCKET)
   - Добавлен SignalR-хаб /hub с JWT-авторизацией
   - События, подтверждения, комментарии, участники
     и группы рассылаются всем подключённым клиентам
     группы мгновенно (notesChanged / commentsChanged /
     participantsChanged / groupUpdated)
   - Индикатор соединения (точка) в шапке приложения
   - Автопереподключение с экспоненциальной задержкой;
     при недоступности WebSocket — резервный опрос раз
     в 45 секунд
   - nginx проксирует WebSocket (map $http_upgrade,
     proxy_set_header Upgrade/Connection)
   - Удалён прежний 15-секундный polling

3. АДМИН-ПАНЕЛЬ
   - Эндпоинты users.web (только роль Administrator):
     * GET  /api/User/all                — список пользователей
     * PUT  /api/User/{id}/reset-password — сброс пароля
       (опционально автогенерация, пароль показывается
       один раз; все сессии пользователя отзываются)
     * PUT  /api/User/{id}/role          — выдача/снятие админа
       (нельзя менять собственную роль)
     * DELETE /api/User/delete/{id}      — удаление пользователя
   - Первый зарегистрированный пользователь становится
     администратором
   - UI: кнопка «Админ» в шапке (видна только админу),
     список пользователей с ролями и статусами
   - GET /api/User/me — текущий пользователь (id, email, роль)

========================================
  БЕЗОПАСНОСТЬ
========================================

1. JWT
   - Токен теперь содержит claims profileId и role
     (вшиваются при входе/refresh)
   - Все контроллеры askdate.web берут profileId из
     токена (fallback на X-Profile-Id для старых токенов)
   - Подделка заголовка X-Profile-Id больше не даёт
     прав другого пользователя

2. USERS.WEB
   - ProfileController: добавлен [Authorize]; смена
     профиля — только владелец или админ
   - UserController: [Authorize] на классе, [AllowAnonymous]
     только на register/login/refresh/verification
   - UpdateUser: проверка владельца (userId из токена)
   - Смена/сброс пароля отзывает refresh-токены
   - DeleteUser реализован (был NotImplementedException):
     удаляет пользователя и связанные профили

3. XSS
   - Весь пользовательский контент (комментарии, названия,
     имена участников, email) экранируется перед вставкой
     в innerHTML (функция esc())

========================================
  ПРОИЗВОДИТЕЛЬНОСТЬ И СТАБИЛЬНОСТЬ
========================================

- GroupService.GetAllAsync: фильтр групп в SQL вместо
  загрузки всех групп таблицы
- UnconfirmSeriesAsync: пакетное удаление подтверждений
  (устранён N+1)
- Комментарии кэшируются на клиенте; realtime-события
  инвалидируют кэш точечно
- Инкрементальное обновление day-panel с сохранением
  выбора и защитой от перезаписи во время редактирования
- Fallback-опрос только при недоступности realtime
- SignalR: автобалансировка транспорта (WS → SSE →
  long polling), автоматическое переподключение
- EF: миграция с defaultValue — безопасна для существующих данных

========================================
  ДЕПЛОЙ
========================================

- Пуш в main → GitHub Actions собирает и публикует
  askdate-web и users-web в Docker Hub (amd64 + arm64)
- На сервере Watchtower подтягивает новые образы за ~60 сек
- Миграция AvailabilityMode применяется автоматически
  при старте askdate.web
- Для nginx изменений не требуется дополнительных действий —
  конфиг обновляется вместе с образом/репозиторием
  (nginx.conf монтируется с хоста — при необходимости
  перезапустить контейнер nginx)
