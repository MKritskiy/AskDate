========================================
  1. ОТМЕТКИ ДОСТУПНОСТИ: ТИП И ВРЕМЯ
========================================

Модель
  - Новая сущность AvailabilityMark:
      Id, GroupId, ProfileId, Date (date),
      Type (1 = свободен, 2 = занят),
      StartTime, EndTime (time without time zone, nullable)
      + Created / LastModified (BaseEntity)
  - Границы времени:
      (NULL, NULL)              — весь день
      (start, end), end > start — интервал [start, end)
      (start, NULL)             — от start до конца дня
        (TimeOnly не выражает 24:00)
  - Ограничение CK_AvailabilityMarks_Interval
    в БД; индекс (GroupId, ProfileId, Date) —
    неуникальный: в дне может быть несколько отметок
  - Участник Participant.AvailabilityMode (int, 2.1)
    → Participant.UnmarkedDaysFree (bool)

Нормализация (Domain/AvailabilityDay.cs)
  - День участника рисуется на линии из 1440 минут
  - Соседние отметки одного типа склеиваются
  - Новая отметка перекрывает другую по типу
    («занят 9–12» поверх «свободен 10–14» →
     «занят 9–12», «свободен 12–14»)
  - Стирание области убирает только отметки
    своего типа («занят 9–12» стереть «10–14» →
     «занят 9–10»); та же операция Paint(line,
     added, erased), зеркально в normalizeDay
  - Отметка на весь день сворачивает интервалы
  - Та же логика повторена на клиенте
    (normalizeDay / computeAvailability), поэтому
    оптимистичная картинка совпадает с ответом
    сервера

API (askdate.web, только участники группы)
  - GET    /api/groups/{id}/availability
  - PUT    /api/groups/{id}/availability
             { dates[], type, startTime?, endTime?,
               replaceIds?, erase? }
           → 200: отметки автора на этих днях
             после нормализации
           erase: true — не ставить, а стереть эту
             отметку (весь день или интервал) на
             указанных днях; действует только на
             отметки того же типа, не сочетается
             с replaceIds
  - DELETE /api/groups/{id}/availability
             { ids[] } или { dates[] } → 200: что осталось
  - DELETE /api/groups/{id}/availability/all → 204
  - PUT    /api/groups/{id}/availability-default
             { unmarkedDaysFree } → 204
  - Время: "HH:mm"; конец "24:00" или "23:59" —
    до конца дня; неверные границы → 400

Права доступа (Security)
  - GroupMembershipAttribute:
      MemberOfGroupAttribute     — группа из route
      MemberOfNoteGroupAttribute — группа через Note
    → 403 не участнику, 404 если цели нет
  - Наложены на Groups (Get/Update/Delete/
    RemoveParticipant/SetAvailabilityDefault),
    Notes, Comments, Availability, GroupHub
  - Вступление только по ссылке:
      POST /api/groups/{id}/participants
      { inviteLink }  (контроллер GroupsController)
  - DomainExceptionHandler (IExceptionHandler):
      KeyNotFound → 404, UnauthorizedAccess → 403,
      ArgumentException → 400, прочее → 500 без
      деталей (ProblemDetails)

Расчёт для группы (фронтенд)
  - Для группы в каждую минуту берётся худшее
    из состояний участников:
    занят > не отметил > свободен
  - Общее окно: непрерывный отрезок FREE не короче
    15 минут, при явной отметке «свободен» в дне
  - Полоса дня = linear-gradient по отрезкам линии
  - Подсказка у события: кто занят в минуту
    события (или в дне, если время не задано)

========================================
  3. ИНТЕРФЕЙС
========================================

Инструменты: «Просмотр» / кисть «Свободен» /
кисть «Занят»; у кисти — «весь день / с–до»
(запоминается в localStorage).

Снятие отметок жестом
  - День, на котором начался жест, решает, что
    он делает (pointerdown запоминает ячейку:
    FullCalendar выдаёт диапазон с началом
    в ранней дате, куда бы ни вели мышь):
      начат на своей отметке типа кисти → стирает
      начат на любом другом дне → ставит
  - Стирается область кисти (весь день или
    интервал) на каждом дне диапазона, только
    отметки типа кисти; дни без таких отметок
    в запрос не попадают (идентификаторы
    остальных не трогаются)
  - Пока жест идёт, у #calendar класс erasing:
    выделение серое вместо цвета кисти
  - Под кистью события календаря (плашки моих
    интервалов, бейджи событий) прозрачны для
    указателя (pointer-events: none): иначе
    FullCalendar не начинает выделение на
    элементе события, и протяжка от плашки
    ничего не делала. В «Просмотре» они
    кликабельны как раньше

Панель дня:
  - «Я: [весь день | с … до …] → Свободен / Занят»
  - список моих отметок дня (изменить / снять)
  - «Все свободны: …» + строка на участника
    с полосой-сутками
  - у события — кто занят на его время

Клиент
  - Оптимистичные отметки: изменение видно сразу
    (временные id < 0, пока нет ответа), затем
    подтверждается ответом сервера; запросы
    идут по очереди (markQueue)
  - Согласование с realtime: пока свой запрос
    в полёте, обновление от SignalR откладывается
  - Время — пары <select> «час : минуты» (24 ч,
    шаг 5 мин); нативный <input type=time> убран:
    он зависит от локали браузера (AM/PM) и на
    узких экранах терял часть суток

Сессия
  - Обновление токена стало single-flight:
      в одной вкладке — один запрос на всех ожидающих;
      между вкладками — блокировка в localStorage
      (askdate_refresh_lock), остальные ждут
      и подхватывают токены
  - storage-событие: выход в одной вкладке
    завершает сессию в остальных

Правки интерфейса
  - Клик по дню открывает только панель дня
  - «Предстоящие»: панель поверх списка
  - Список участников: перенос вместо обрезания;
    участник удаляет только себя, создатель —
    только других
  - Логин и роль в профиле
  - SVG-иконки вместо эмодзи и текстовых знаков
  - Локализация кнопки «Сегодня» и подсказок
    FullCalendar (через MutationObserver: тексты
    панели инструментов кэшируются при создании)
  - Полосы доступности рисуются синхронно
    (requestAnimationFrame не срабатывает
    в скрытой вкладке)
  - Диалог подтверждения вынесен из .modal:
    любая модалка делала его невидимым (2.1)
  - Список групп обновляется на месте
  - Бейджи: «19:30 · 2 уч.», на телефоне — время
  - Кэш статики: Cache-Control: no-cache (ETag)
  - iCal: локальное время вместо UTC
